# Contributing

Thank you for helping to keep this list useful.

- **Suggest a resource** by opening an issue or a pull request. Add it to the section that fits, with a one-line description in plain words.
- **Ask a question or share something you made** in [Discussions](https://github.com/ArtisanStrategies/awesome-journaling/discussions).

A resource belongs here if it is:

- about keeping a journal or diary, or about writing that people do for themselves;
- free to use, or a widely available book, notebook or app;
- accurate, and still online.

Please check the link before you add it.
